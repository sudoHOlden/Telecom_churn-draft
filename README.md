# Telecom Churn Prediction

Анализ и подготовка данных клиентов телеком-компании для предсказания оттока.

## Что в проекте

- `data.csv` — датасет с информацией о клиентах (7043 записи)
- `pd.ipynb` — ноутбук с анализом и очисткой данных

## О данных

Таблица содержит информацию о клиентах:
- демография (пол, возраст, семейное положение)
- услуги (телефон, интернет, стриминг и т.д.)
- тип контракта и способ оплаты
- месячные и общие расходы
- целевой признак: `Churn` (остался или ушел клиент)

## Что делает notebook

1. Загружает данные и п��оверяет структуру
2. Чистит данные:
   - преобразует `TotalCharges` в число
   - заполняет пропуски средним значением
3. Кодирует категории:
   - Yes/No → 1/0
   - Пол, контракт, интернет, оплата → числовой формат
4. Удаляет `customerID` (не нужен для модели)
5. Подготавливает матрицу признаков (7043 × 27)

На выходе получаются данные, готовые для обучения классификатора.

## Что дальше

В notebook импортированы инструменты для обучения модели:
- `train_test_split` — разбиение на train/test
- `RandomForestClassifier` — модель
- `classification_report` — метрики

Можно обучить модель и проверить точность на тестовой выборке.
